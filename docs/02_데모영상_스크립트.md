# 데모 영상 스크립트 (약 2~3분)

화면 녹화 + 본인 목소리 내레이션으로 녹화하시면 됩니다. 괄호 안은 화면 동작, 큰따옴표는 그대로 읽으셔도
되는 대사(참고용, 자연스럽게 바꾸셔도 됩니다).

---

## 1. 오프닝 (10~15초)

(화면: 타이틀 슬라이드 또는 로그인 화면)

> "VPN 없이, 브라우저만으로 사내 시스템에 접속한다 — OfficeBridge입니다.
> 지금부터 실제 저희 회사 ERP와 GitLab에 직접 접속하는 걸 보여드릴게요."

---

## 2. 로그인 (15초)

(화면: `https://portal.10-52-249-21.sslip.io/` 접속 → 인증서 경고 "고급 → 계속 진행" → 로그인 화면
→ 데모 계정 칩 `김영업 (영업팀)` 클릭 → 로그인 버튼)

> "영업팀 계정으로 로그인합니다. 별도 VPN 클라이언트 설치 없이, 그냥 브라우저입니다."

---

## 3. 포털 → 실제 ERP 접속 (20초)

(화면: 사내 시스템 포털 카드들 → ERP 카드 클릭 → 실제 ERP 로그인 화면이 뜨는 것을 보여줌)

> "포털에 이 계정이 접근 가능한 시스템만 카드로 보입니다. ERP를 클릭하면—
> 실제 저희 회사 ERP 로그인 화면이 그대로 뜹니다. 뒤에서는 릴레이가 인증하고,
> 사내망에 있는 커넥터가 실제 ERP로 요청을 중계하고 있는 거예요."

---

## 4. 정책 미허용 차단 (15초)

(화면: 주소창에 `https://gitlab.10-52-249-21.sslip.io/` 직접 입력 → 403 차단 화면)

> "같은 계정으로 GitLab에 들어가 볼게요. 영업팀은 GitLab 권한이 없어서, 이렇게 차단됩니다.
> 이건 프론트에서 숨긴 게 아니라 — 권한 없는 시스템엔 요청 자체가 사내망에 도달하지 않습니다."

---

## 5. 관리자 콘솔 — 정책 실시간 변경 (30초)

(화면: 로그아웃 → `admin@demo.co.kr`로 로그인 → 우측 상단 아바타 클릭 → "관리자 콘솔" →
사이드바 [정책 접근관리] → 영업팀 행에서 GitLab 칩을 클릭해 켜기)

> "관리자로 들어가 보겠습니다. 정책 접근관리에서 영업팀에 GitLab 권한을 지금 바로 켜볼게요."

(화면: 새 탭 또는 다시 로그인해서 영업팀 계정으로 GitLab 접속 → 이번엔 통과되는 것을 보여줌)

> "방금 켠 게 재배포나 재시작 없이 바로 반영됩니다 — 이제 영업팀도 GitLab에 들어가지네요."

(원상복구를 원하시면 다시 꺼두고 녹화 이어가시면 됩니다.)

---

## 6. 행위 기반 지속 검증 (15초)

(화면: 관리자 콘솔 [행위 기반 제어] 메뉴를 잠깐 비춰줌 → 사내 시스템 페이지에서 새로고침을
빠르게 여러 번 눌러 차단 화면 띄우기)

> "로그인 이후에도 계속 지켜봅니다. 예를 들어 짧은 시간에 요청을 비정상적으로 많이 보내면—
> 이렇게 자동으로 차단됩니다. 로그인 한 번으로 끝나는 게 아니라, 세션 내내 행위를 검증합니다."

---

## 7. 감사로그 (10초)

(화면: 관리자 콘솔 대시보드 또는 [시스템 접속로그]로 이동, 실시간으로 로그가 쌓이는 것을 보여줌)

> "지금까지의 모든 로그인/접속/차단 기록이 실시간으로 감사로그에 남습니다."

---

## 8. 클로징 (10~15초)

(화면: 타이틀 슬라이드 또는 아키텍처 다이어그램)

> "VPN 설치도, 사내망 전체 노출도 없이 — 필요한 시스템에, 필요한 사람만, 계속 검증하면서
> 접속하게 하는 것. 그게 OfficeBridge입니다. 감사합니다."

---

## 촬영 팁

- 4~8번은 순서를 좀 바꾸거나 시간이 부족하면 6번(행위기반)은 짧게 언급만 하고 넘어가도 됩니다.
- 브라우저 확대(Cmd + `+`)를 한 단계 정도 해두면 화면 녹화했을 때 글자가 더 잘 보입니다.
- 인증서 경고 화면은 데모 흐름을 끊으니, 녹화 시작 전에 한 번 미리 "계속 진행"을 눌러 인증서
  예외를 등록해두고, 녹화 중엔 그 부분을 생략하는 것을 추천합니다.
