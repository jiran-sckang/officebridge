## 계정

MVP를 실서비스처럼 쓰기 위해 데모 계정은 전부 제거하고, 관리자 1명(회사코드 `AMD`)만 시드로 등록한 뒤
실제 임직원을 조직도에서 직접 추가해가며 운영 중입니다. 로그인은 **회사코드 + 이메일 + 비밀번호** 세
가지가 모두 필요합니다. 심사 시 필요한 관리자/임직원 계정 정보는 발표 또는 시연 시 별도로 안내드립니다.

## 둘러볼 포인트

1. **회사코드 로그인 게이트** — 포털/브릿지/커넥터 로그인 모두 회사코드(`AMD`)가 먼저 맞아야 합니다.
2. **VPN 없이 브라우저만으로 접속** — 포털에 로그인하면 본인이 접근 가능한 사내 시스템 카드가 뜨고,
   클릭하면 바로 해당 시스템 화면(실제 사내 ERP/GitLab 등)이 뜹니다. 정책 미적용 시스템은 아예 안 보임.
3. **자가등록 데스크톱 앱 (Windows/Mac)** — [설치 파일] 페이지에서 로그인 없이 바로 받을 수 있습니다.
   - **브릿지 앱**(임직원용): 최초 1회 회사코드+계정 인증 후 로그인 없이 클릭 한 번으로 접속.
   - **커넥터 앱**(관리자용, 사내망 설치): 관리자 로그인(+MFA)이 있어야만 터널이 열림.
4. **관리자 콘솔** — 관리자 계정으로 로그인 후 상단 아바타 → [관리자 콘솔]. 조직도(회사→부서→임직원
   트리, 검색, 톱니바퀴 메뉴로 사용자 수정/삭제), 정책접근관리, 행위기반 제어, 계정통제, 2차 인증(MFA)
   설정, 실시간 접속 로그를 볼 수 있습니다.
5. **접근 회수 → 자동 로그아웃** — 조직도에서 임직원의 "접근 회수"를 누르면, 그 사람의 브릿지 앱이 다음
   폴링 주기(최대 15초) 내에 자동으로 로그아웃 화면으로 전환됩니다.
6. **행위 기반 지속 검증** — 로그인 후 같은 사내 시스템 페이지를 짧은 시간 내 과도하게 새로고침하면
   자동 차단됩니다. [행위 기반 제어]에서 규칙별 on/off 가능.
7. **MFA(2차 인증)** — [2차 인증] 메뉴에서 계정별로 필수 지정 가능. 필수인데 아직 등록 전인 계정은
   커넥터 로그인이 막히고, 포털에서 먼저 본인이 등록하라는 안내가 뜹니다.
